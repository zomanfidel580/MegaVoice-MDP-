Jeu de guitare

Legato : tenez une note puis appuyez sur une touche voisine, ou glissez le doigt sur le clavier : la nouvelle note sonne sans coup de médiator. Glisser change de note, sans pitch bend. Les bruits de doigts se déclenchent quand on enchaîne vite.

Glissando et slide

Chaque glissé produit un « zzziit » de doigt sur la corde. Dead note / chuck : bouton « Dead note » (ou touche Maj sur PC) pour la corde étouffée, le petit « tchic » percussif.

Touche maintenue

S.Art2 (Super Articulation 2)

Bouton S.Art2 sous l’écran. L’articulation suit votre jeu : notes liées = legato (hammer-on / pull-off), note courte = staccato étouffé, note forte tenue = chute de hauteur au relâchement, et les zones de vélocité choisissent l’articulation. Le bruit de doigts et le slide restent réglables ci-dessous.

Voice Effect

Bend

Molette de hauteur (±2 tons) et de modulation (vibrato) à gauche du clavier ; un clavier MIDI les pilote aussi.

Affichage

Registration Sequence

Ordre de rappel des mémoires de la banque (boutons ◀ Seq / Seq ▶ ou pédale).

Foot Pedal

Pédale MIDI : CC64. À l’écran, le bouton « Pédale ».

Réglages

MIDI : la ligne d’état sous l’écran indique les appareils détectés. Les molettes, la modulation, le changement de programme, le volume et Start/Stop sont pris en charge.

Clavier

RIGHT 1 joue la voix de l’onglet Voix, RIGHT 2 se superpose avec sa propre voix, LEFT joue sa voix à gauche du split. Avec ACMP, la main gauche pilote aussi les accords du style (clavier, souris, tactile ou MIDI).

Styles intégrés

Kit de batterie

Pack de batterie : choisissez un fichier par instrument ci-dessus, ou sélectionnez plusieurs fichiers d’un coup (noms contenant kick/bd, snare/sd, clap, hat/hh, open/oh, crash, ride, tom). Vos sons sont conservés sur cet appareil et forment le kit « Mon kit perso », sélectionné automatiquement et utilisé par les styles et les pads ; un instrument sans fichier reste synthétisé. Les toms sont accordés automatiquement.

Style (fichier)

Aucun style chargé
Accord : C maj

Instrument de chaque partie du style

Fichiers lus : styles .STY (Yamaha SFF) et .MID avec marqueurs de sections. Les sons de l’accompagnement sont synthétisés par l’app (batterie, basse, accords), pas ceux de votre clavier Yamaha.

Le nom du fichier doit contenir la note (E2, A#3, Gs3). Avec « Selon le nom », la zone se lit dans le nom : v1 à v5, etouffe, doux, normal, fort, slap, harm. Sinon tous les fichiers vont dans la zone choisie. Les notes sans fichier sont obtenues en transposant l’échantillon le plus proche. Pour la partie de fin (bruit de relâchement), ajoutez fin ou release au nom (ex. E2_fin.wav).

Enregistreur

0:00Prêt à enregistrer

Un enregistrement garde deux choses : le son complet (voix, style, pads, effets) et les notes jouées au clavier. Les notes peuvent être rejouées avec une autre voix.

Exporter

Le fichier .mid contient les notes jouées au clavier (pas le style ni les pads) et peut être chargé dans un clavier ou un logiciel de musique.

Composants par zone de vélocité

Un fichier par note et par partie : la note dans le nom (E2, A#3) et la partie : etouffe, doux, normal, fort, slap ou harm, fin ou release pour le relâchement. Exemple : E2_etouffe.wav, E2_fort.wav, E2_fin.wav.

L’instrument reprend l’égalisation, l’ADSR et les effets du modèle, que vous réglez ensuite dans Son. Ajoutez vos échantillons par zone dans l’onglet Échantillons.
